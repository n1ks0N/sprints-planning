Для выбранных полей дополнительно сверены точные значения before/after. Для повторных значений и отката записи отсутствуют.

При одновременном применении вторая операция получает 400/409 согласно текущему контракту, изменения и событие выполняются один раз. При гонке с удалением DELETE завершается; применение либо завершается первым, либо получает 400/404/409. Проверяются отсутствие 500 и количество предметных событий.

Экспорт Jira выполнен только с APP_JIRA_MOCK_ENABLED=true. Внешняя Jira не изменялась. История содержит отдельное событие Story и по событию для двух задач участников.

Исправлены пропуски workspace, allocations/loads, самостоятельной нагрузки, ручных ссылок Jira и Story. Уже существующие события не переписываются. Все изменения задачи и её предметная история фиксируются общей транзакцией; общий асинхронный HTTP-журнал сохраняет прежнюю семантику.

Для повторения: `python3 scripts/backend-audit-history.py --output /tmp/backend-history.json`. Скрипт проверяет отдельный контейнер и mock-режим, создаёт собственную команду и удаляет её в finally.
